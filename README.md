# 산업안전기사 필기 학습

[앱 열기](https://joodraw.github.io/safe/)

2020–2025년 17개 회차의 제공 자료를 활용한 모바일 중심 학습 앱입니다.

## 기능

- 홈, 회차·과목별 학습, 검색, 복습, 통계
- 2,029개 학습 카드와 원문 해설
- 12개 개념의 쉬운 설명과 기억할 점, 스스로 확인하기
- 알아요·다시 학습, 아리까리, 즐겨찾기
- 브라우저 학습 기록 저장, 학습 평가 취소

객관식 보기가 없는 요약 자료를 사용하므로 자기 평가 방식입니다. 추가 설명은 관련 개념이 포함된 카드에 표시됩니다. 법령과 수치는 원문 기준이며 현행 법령 대조는 수행하지 않았습니다.

## 실행

```sh
npm ci
npm run build
npm run preview
```

개발 서버: `npm run dev`. 제한된 Windows 환경에서 개발 의존성 최적화가 실패하면 빌드 후 미리보기를 사용하세요.

## 데이터

`source.md`를 `npm run import`로 변환합니다. 2,029개 카드가 2,033개 문제 번호를 표현합니다. 원문 머리말의 2,036문항 표기와 차이가 있으며 없는 문항을 생성하지 않았습니다. 회차별 카드 수는 `public/data/import-report.json`을 참고하세요.

## 배포

저장소의 GitHub Pages 소스를 GitHub Actions로 설정합니다. main 브랜치 갱신 시 `.github/workflows/deploy.yml`이 빌드하고 게시합니다.
